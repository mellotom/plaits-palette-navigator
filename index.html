01

load your palette

plp_01
step 1
on plaits palette, press save configuration, top right of “arrange your palette”
step 2
it saves a file ending in .plaits-palette.json. this is separate from download firmware wav, which doesn’t include it
step 3
drop that file below. the guide to your firmware builds itself
or drag the file onto this box · nothing is uploaded, it is read in your browser

once loaded, this browser remembers your palette. the share link opens the same guide on any device, no file needed.

04

install the firmware

plp_04 · audio update
before 1
unplug every cable from the module
before 2
patch your computer or audio interface output into the model input
before 3
set frequency to 12 o’clock
before 4
silence notifications and anything else the computer might play. disconnect speakers and headphones: the update audio is loud
before 5
no equalizer, automatic gain or other effect between the file and the module
step 1
hold [ left ] while you power on the system
step 2
play the firmware .wav from start to finish
LEDs 1–4
level meter. two or three lit is right. turn frequency to change the input gain
LEDs 5–8
progress of the packet being received
step 3
when the file ends the module restarts on its own. if it doesn’t, start over
all LEDs blink red
the level is off. press [ left ] and play the file again with more gain. a computer’s line output may need full volume. still failing: try another computer or interface

procedure from the mutable instruments plaits manual · the palette .wav installs the same way
